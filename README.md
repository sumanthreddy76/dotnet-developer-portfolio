# Sumanth — Full Stack .NET Developer Portfolio

A self-contained, responsive portfolio with working browser demos for document-grid sorting, accessible dialogs, form validation, and focus recovery. All data is fictional. This is **not** the original TN PDMS application, and it does not include proprietary employer source code.

## Run
Open `index.html` in a browser. No installation required.

## Publish on GitHub Pages
1. Create a new **public** GitHub repository (for example `dotnet-developer-portfolio`).
2. Upload `index.html` and `README.md` to the repository root and commit.
3. Open **Settings → Pages → Build and deployment**; choose **Deploy from a branch**, `main`, `/ (root)`, and Save.
4. Once deployment completes, your portfolio URL will be `https://sumanthreddy76.github.io/dotnet-developer-portfolio/`.
5. Open the published link on mobile and desktop and verify the four interactive demos before sharing.

## Important technical scope
The demos run entirely in browser-side JavaScript. The C# code is illustrative, not compiled or executed. For a true deployed .NET + SQL Server sample, add a separate ASP.NET Core API and a hosted database using original, synthetic data.
